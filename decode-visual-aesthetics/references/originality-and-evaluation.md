# Originality and Evaluation

Learn aesthetic mechanisms without duplicating recognizable expression.

## Retain versus redesign

Usually retain abstract relationships such as:

- warm subject against a cool field;
- low-key side lighting with restrained fill;
- large negative space used to create isolation;
- slow lateral camera motion used to reveal information;
- simplified value groups and soft edge hierarchy;
- long holds followed by short bursts of cutting.

Redesign recognizable expression such as:

- named or distinctive characters;
- signature costumes, props, locations, or production design;
- exact subject placement from a famous image;
- a distinctive shot order or action sequence;
- recognizable dialogue, text, symbols, or logos;
- a close recreation intended to substitute for the source.

## Originality-distance gate

Before production, redesign at least three of these five dimensions:

1. subject or character relationship;
2. setting and production design;
3. narrative function or conflict;
4. visual motif and prop system;
5. staging, action, or ending logic.

If fewer than three change, increase distance before writing prompts.

For living artists or highly distinctive contemporary creators, prefer a descriptive attribute-based direction rather than requesting a direct signature-style imitation.

## Two-axis evaluation

Score both axes separately. A visually faithful result can still fail originality.

### Aesthetic-logic fidelity — 16 points

Score each 0–2:

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| palette hierarchy | unrelated | partly aligned | relationships preserved |
| tonal structure | unrelated | approximate | curve and separation preserved |
| lighting geometry | arbitrary | partly motivated | direction, softness, and falloff preserved |
| composition | weak or copied literally | partial hierarchy | function preserved with new staging |
| optics and depth | contradictory | plausible | perspective and focus support the logic |
| texture and materials | synthetic or generic | mixed | coherent surface response |
| motion and editing | unmotivated | partly aligned | rhythm serves the same function |
| system coherence | layers conflict | mostly coherent | all layers reinforce one thesis |

Interpretation:

- **14–16:** strong production candidate; test with viewers.
- **11–13:** revise the two weakest dimensions.
- **8–10:** rebuild composition, light, or motion hierarchy.
- **0–7:** redefine the visual thesis.

### Originality distance — 8 points

Score each 0–2:

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| characters and setting | recognizable duplication | partial redesign | clearly independent |
| staging and composition | near-copy | similar scaffold | new arrangement with retained function |
| motif and narrative use | source-specific | mixed | original motif and function |
| overall substitution risk | could replace or be confused with source | some confusion | clearly transformative and independent |

Require at least 6/8 before presenting a “ready to produce” prompt set.

## Common failures and fixes

| Failure | Cause | Fix |
|---|---|---|
| adjective soup | labels replace relationships | rewrite as observable spatial, tonal, and temporal rules |
| reference contamination | one asset controls too many layers | assign one role and explicit exclusions per asset |
| famous-frame cloning | composition copied instead of function | preserve attention pathway but redesign staging and geometry |
| palette-only imitation | color mistaken for the whole style | add light, depth, optics, texture, blocking, and rhythm |
| unsupported lens certainty | visual estimate presented as metadata | use focal-family language and confidence labels |
| static-to-motion invention | movement inferred from one still | mark motion as a new interpretation and test alternatives |
| AI gloss | uniform sharpness, perfect surfaces, unmotivated rim light | restore material variation, focus hierarchy, source-motivated light, and controlled finishing |
| inconsistent series | every shot uses a different reference logic | lock five to eight fixed rules and vary one major layer per test |

## A/B testing

Change one primary variable at a time:

- same composition, different light ratio;
- same light, different palette separation;
- same keyframe, different camera path;
- same motion, different texture finish;
- same visual DNA, different original setting.

Judge with the two-axis scorecard and viewer response. Do not select only by superficial resemblance.
