# Ancient Painting Cinematic Realizer

把古画视为一套叙事、姿势、动势、构图、色彩和情绪规则，而不是需要逐线描摹的轮廓。保留作品的神韵与关系，按照真实人体、材质、空间、摄影和光线逻辑重新搭建可拍摄的电影场景。人体正确性和原画忠实度是并列硬门槛：不能用原画姿势为人体错误让步，也不能以修复人体为由更换动作、风势或情绪。

## 判定输入角色

先识别每张输入图的用途：

- 将古画、壁画、卷轴或传统插图指定为主母本。
- 将额外图片分别标记为色彩、光线、服装、材质、场景或摄影参考。
- 用户只提供一张古画时，从该画同时提取构图、叙事、色彩和气质，不要求补充色卡。
- 用户提供多张图但未说明用途时，根据内容作出合理分配，并在输出中用一句话说明假设。
- 仅迁移辅助参考的视觉属性，不擅自复制其中的人物、道具、建筑或构图。

只有在缺失信息会实质改变结果时才提问。否则先按最可信的默认方案执行。

## 执行工作流

### 1. 读取古画结构

提取并记录：

- 画幅、视觉动线、主体层级和留白位置
- 人物数量、相对位置、朝向、动作、视线与距离
- 头部角度、躯干轴线、骨盆位置、肢体弯曲与承重点
- 衣袖、衣摆、披帛、发丝和悬挂物形成的方向性动势
- 风从何处来、强弱如何、哪些部位被吹动、哪些锚点保持稳定
- 核心道具、仪式行为、冲突或观看关系
- 前景、中景、背景及其遮挡关系
- 主色、辅色、强调色、冷暖、明度与饱和度节奏
- 宁静、神性、荒诞、肃穆、世俗或梦境等情绪

不要把含混的画面元素过度解释成确定故事。区分可见事实、合理推断和创作补足。

### 2. 建立“保留—重建”清单

必须保留：

- 构图骨架与视觉重心
- 人物和主体之间的关系
- 人物姿势、头部角度、躯干倾斜、肢体方向、手脚落点和承重方式
- 视线、表情、肌肉松紧和叙事张力
- 衣袖、衣摆、披帛、发丝与道具的风向、速度感和运动轨迹
- 留白形状、主体尺度、疏密节奏和画面呼吸
- 核心道具的功能与象征
- 原作色彩精神、意境、情绪强度和东方气质

必须重建：

- 平面或装饰性透视
- 概括、变形或不完整的人体
- 手、脚、关节、重心和接触点
- 线描衣纹所代表的真实布料褶皱
- 建筑、道具和人物之间的尺度关系
- 绘画笔触所代表的真实材质与空气层次

发生冲突时，在原动作内部重建正确人体，不要换成更容易生成的标准站姿、坐姿或摆拍动作。若第一次生成无法同时满足姿势忠实与人体正确，保持原画姿势重新生成，直到两道门槛同时通过。

### 3. 锁定姿势、风势、意境与情绪

在设计现实场景前建立四张内部映射：

1. **姿势地图**：标记头部角度、视线方向、肩线、脊柱轴、骨盆位置、肘膝弯曲、手脚落点、接触物和身体重心。保留人物是站、坐、跪、卧、回望、俯身、对峙或行走，禁止改变动作类别。
2. **风势地图**：提取风向、强度和节奏，区分由风、动作或重力造成的褶皱。标记衣领、肩、腰带等固定锚点，以及袖口、衣摆、披帛、发丝等自由端的运动方向、弧线和幅度。
3. **意境地图**：提取留白、远近虚实、疏密、空间压迫或开阔、时间感、天气和环境声音想象。把留白转译为空气与空间，不用无关景物填满。
4. **情绪地图**：依据表情、视线、姿态张力、人物距离、色彩明度和空间节奏判断情绪。区分可见证据与创作推断，不擅自把孤寂变成英雄感、把克制变成浪漫、把肃穆变成华丽。

将以上映射写入生成提示词的前半部分，优先于镜头、置景和材质修饰。原画中的风吹衣袂必须在现实布料中继续存在：固定端稳定，自由端顺风延伸，褶皱从受力点向外传播，风向在衣服、头发、植物和尘雾之间保持一致。

不得为了人体稳定而取消风势、拉直衣袖、放下抬起的手臂、改变盘坐或行走方向，也不得把具有叙事张力的姿态改成面对镜头的普通肖像。人体修复只校正比例、关节和受力，不改变动作语义。

### 4. 转换为可拍摄场景

把绘画语言转换为摄影语言：

- 将留白转换为空气、负空间、雾、浅色墙面、天空或景深。
- 将平面设色转换为主色明确、辅助色克制的电影调色系统。
- 将云气或神性转换为有方向的薄雾、体积光、半透明织物和庄重表演。
- 将装饰线条转换为真实结构、材质边缘或光影分界，不生成浮雕式笔触。
- 将轻微荒诞转换为现实空间中的尺度、行为或仪式逻辑异常，不随机堆叠奇观。

选择与原作一致的场景类型，如殿堂、庭院、长廊、山石、水边、室内外过渡空间或生活化古代室内。建立明确的前中后景、地面接触、遮挡和空气透视。

### 5. 锁定人体结构与服装

把人体正确性设为不可妥协的硬约束，优先级高于服装装饰、氛围和逐轮廓复刻。生成前为每个人建立结构链：

- 头部—颈部—脊柱—骨盆必须连续，肩宽、躯干长度和头身比例自然。
- 左右肩—肘—腕—手必须各自形成一条可解释的受力链，不出现多余、缺失、融合或从衣物中凭空伸出的肢体。
- 左右髋—膝—踝—脚必须与站姿、坐姿和重心一致，不出现反关节、错向、悬空或长度冲突。
- 先确定每只手的动作和接触对象，再描述手腕角度、掌心方向、手指弯曲和抓握点。持扇、执杯、托物、扶栏等动作必须符合真实受力。
- 可见手指必须数量合理、彼此分离、关节清楚；被遮挡的手指必须符合遮挡逻辑，不强行展示全部手指。
- 全身构图中，让双脚清晰正确地落地；若原画以长袍完全遮脚，则保持自然遮挡和可信重心，不生成半露、粘连或变形脚掌。

让宽袖和长袍覆盖在已成立的人体结构上，而不是用布料掩盖错误。根据手臂路径、人体动作、重力、面料厚度、束带和受力点重新建立褶皱。区分丝绸、绢、锦缎、薄纱、棉麻、木、石、金属与陶器的反射和纹理。

不要直接复制古画衣纹、概括肢体或装饰轮廓。遇到局部人体不明确时，根据整体姿势地图补足最合理的关节与遮挡；只简化不可见的微小手指关系，不改变交叉手臂、盘腿、回望、俯身、行走或迎风等核心动作。

### 6. 设计电影摄影

优先采用能服务叙事的克制摄影方案：

- 使用柔和窗光、清晨或傍晚漫射光、细腻侧光、轻微逆光或雾中方向光。
- 保持光源动机清楚，避免互相冲突的多光源。
- 根据构图选择镜头；环境关系重要时倾向 28–40mm，人物状态重要时倾向 50–85mm。
- 保留原作的观看高度和视觉重心，除非真实透视必须调整。
- 使用自然景深、适度镜头呼吸和真实曝光，不用过度锐化或强轮廓光制造“电影感”。

最终画面应像经过美术指导、服装、置景和摄影共同完成的电影剧照，而不是汉服写真、古偶宣传照或游戏角色渲染。

### 7. 去除 AI 塑料感

主动加入真实世界的不完美：

- 保留皮肤纹理、细小色差、自然毛孔和轻微不对称。
- 让服装存在使用痕迹、压褶、摩擦和重力形变。
- 让建筑和道具具有年代、灰尘、磨损和触摸痕迹，但不要统一铺设“脏旧滤镜”。
- 让人物脚底、衣摆、座具和道具发生可信接触。
- 控制雾、光晕、景深和颗粒，避免把所有区域同时柔化。

避免瓷娃娃皮肤、蜡像面部、规则重复纹理、漂浮物体、无重力织物、空洞布景和均匀棚拍光。

## 色彩迁移

只有主母本时：

1. 提取 3–6 个关键颜色及其功能。
2. 保留综合色温、明度层次和强调色比例。
3. 将绘画颜料转化为环境、服装、肤色和光线中的现实颜色。
4. 允许为自然肤色和曝光适度降低饱和度或压缩对比。

存在外部色彩参考时，只迁移冷暖、色相关系、明度节奏和饱和度分布。不要复制参考图中的主体或场景。

不要套用单一滤镜。分别描述高光、肤色、中间调、阴影和环境反射色。

## 选择输出模式

### 分析与提示词

用户要求分析、方案或提示词时，按以下顺序输出：

1. **原画读图**：用简洁语言说明构图、人物关系、色彩和情绪。
2. **保留与重建**：列出必须保留的视觉锚点和必须现实化的结构。
3. **电影化方案**：给出场景、镜头、光线、材质和表演方向。
4. **生成提示词**：优先给出一段完整中文提示词；用户需要时再给英文版。
5. **负面约束**：仅列与本画面相关的失败模式，不堆砌无关关键词。

提示词必须明确：主母本、构图锚点、人物关系、现实修正、环境层次、镜头、光源、材质、色彩系统和需要排除的风格。

### 直接生成图像

用户要求直接生成时，先在内部完成姿势、风势、意境、情绪和人体结构规划，再调用可用的图像生成或编辑工具。将主母本作为结构参考，将辅助图按其角色使用。生成后先执行“原画忠实度验收门槛”，再执行“人体结构验收门槛”；任一未通过时不得作为最终结果交付。最终只附简短说明，不展开冗长推理。

### 古画动态化或视频首帧

用户要求视频、动态短片或 Seedance 首帧时：

- 先设计一个忠于原画构图的英雄首帧。
- 把动作限制为可拍摄的微动作，如呼吸、衣摆、薄雾、烛火、视线或缓慢转身。
- 指定主体运动、环境运动和镜头运动，避免三者同时剧烈变化。
- 保持人物数量、服装、道具、光向和空间连续。
- 输出首帧图像提示词、图生视频运动提示词和负面约束。

### 现代化转译

仅在用户明确要求时执行。保留原构图、人物关系、观看方式和象征功能，把身份、服装、空间与器物转换为现代对应物。不要只给古装人物换现代衣服；应重建完整的社会场景与叙事逻辑。

## 提示词骨架

将以下字段自然整合成一段提示词，不机械显示占位符：

```text
[主母本与画幅] + [姿势地图与手脚落点] + [风向、受力锚点和衣袂动势] +
[留白、意境与情绪] + [必须保留的构图和人物关系] + [现实场景与时代细节] +
[人体、服装和材质修正] + [前中后景与摄影透视] + [镜头、机位、景深] +
[有动机的光线] + [从原画或色卡提取的调色系统] + [真实质感与情绪] +
[排除古偶写真、游戏渲染和 AI 塑料感]
```

不要使用空泛词语替代可执行描述。“高级”“电影感”“史诗”必须由具体镜头、光线、材质、构图或色彩决定。

## 原画忠实度验收门槛

先把生成图与原画逐项对照，再进行人体检查：

1. 人物数量、主体尺度、画面位置和留白分布是否一致。
2. 站、坐、跪、卧或行走等动作类别是否未变；头部角度、躯干轴、骨盆高度、肘膝方向、手脚落点和视线是否对应。
3. 衣袖、衣摆、披帛、发丝和道具的运动方向、弧度与强弱是否延续原画；是否出现原画有风而生成图静止的情况。
4. 原画的空间是空旷、压迫、疏朗、幽深还是封闭，生成图是否保持同类空间感，而非用写实细节填满留白。
5. 人物表情、姿态张力、明暗、色彩和环境是否共同传达与原画一致的情绪强度。
6. 现实化是否只重建材质、空间和结构，没有把原画变成普通正面肖像、古装写真或另一段故事。

以下任一情况均判定失败：改变人物动作类别、移动核心手脚落点、取消或反转风势、让衣袂失去原有运动弧线、明显改变视线和情绪、填满关键留白、改变主体比例，或虽精致写实却失去原画意境。

验收失败时，保留已经正确的人体与材质，只针对姿势、动势、留白或情绪做定向编辑；若局部编辑无法恢复原画关系，则按原画姿势地图重新生成。未通过忠实度门槛时，不得进入最终交付。

## 人体结构验收门槛

通过原画忠实度门槛后，把每张生成图按原始清晰度检查，逐个人物验收以下区域：

1. 头部、颈部、肩部和躯干是否连续，是否存在不可能的扭转或拉长。
2. 左右上臂、肘、前臂、腕和手是否能沿身体追踪，是否存在多肢、断肢、融合或左右混乱。
3. 每只可见手的掌心方向、拇指位置、手指数量、关节和接触点是否与动作一致。
4. 骨盆、左右大腿、膝、小腿、踝和脚是否符合透视、承重和地面接触。
5. 衣袖、披帛和长袍是否只是覆盖人体，而没有把手臂、手或腿错误地融合成布料。
6. 人物与团扇、杯、乐器、栏杆、座椅等道具是否存在真实抓握、托举或接触关系。

以下任一情况均判定失败：多余或缺失肢体、手指融合或增生、手腕折断、肘膝反向、双臂或双腿长度矛盾、肢体从错误位置出现、身体异常拉长或扭曲、道具穿过手掌、脚掌悬空或粘连、长袍下出现无法解释的腿脚结构。

验收失败时：

- 不要把失败图展示为最终结果，也不要仅靠追加负面词掩盖问题。
- 优先对最小问题区域做定向编辑，明确“只修复该肢体，其他人物身份、构图、服装、光线和背景全部保持不变”。
- 局部编辑破坏整体时，重新生成，并把姿势简化为更稳定的现实动作。
- 修复后重新执行完整验收；仍未通过时明确说明限制，不声称已经完成。

## 最终自检

输出或生成前逐项检查：

- 构图、人物数量和关系是否仍可对应原画？
- 人物动作类别、头部角度、躯干轴、肘膝方向和手脚落点是否遵照原画？
- 风向、衣袖与衣摆弧线、发丝和环境运动是否保持统一并延续原画动势？
- 留白、疏密、空间感、意境和情绪强度是否与原画一致？
- 色彩是否保留原作精神，而非简单滤镜？
- 是否已逐个人物完成头—躯干、肩—肘—腕—手、髋—膝—踝—脚的结构追踪？
- 可见手指、手腕、抓握点、脚掌和承重是否全部通过人体结构验收门槛？
- 衣褶是否由面料、动作和重力决定？
- 空间是否有正确尺度、透视和前中后景？
- 光源是否统一且有现实动机？
- 皮肤、道具和环境是否具有非重复的自然细节？
- 是否避免古偶宣传照、普通汉服写真、仙侠游戏、3D 渲染和塑料质感？
- 若为视频，首帧是否有清晰主体，运动是否连续且不过载？

发现原画忠实度、人体或其他关键结构错误时，先局部修复或重新生成，再依次从原画忠实度和人体结构两道门槛重新验收；任一未通过时不得输出为最终图像。
